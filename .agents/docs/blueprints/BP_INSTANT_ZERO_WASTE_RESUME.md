## 3. Cold-Ctx Red-Team, Pre-Mortem & Kill Criteria
PREMORTEM|T+6mo|Fresh AI Studio container boots slower than `12s` quiescence window w/o `GITHUB_TOKEN`, detects delayed hydration files, && overwrites prior session's active remote bundle OR `resume` skips Termux probe while Cloud DO exceeded `140 KB` inline cap, silently missing large uncommitted edits. Defense: (1) Remote Active-Unrestored Guard ALWAYS probes `fr_latest` before first remote push in a fresh container (if remote `status=active` && `hasBundle=True` w/ unmatched disk hashes -> pause mirroring `paused_remote_rollback_protected`); (2) `resume` probes Local + Cloud (`fr_latest`+`fr_semantic`) + Termux (`latest.json`+`semantic.json`+dirty-vs-origin) in parallel (`6s` cap, `auto_wake=False`) && emits explicit `ROLLBACK_TERMUX` / `TERMUX_UNCOMMITTED` when Termux holds newer uncommitted files.
THREAT|Stale/poisoned `live_mirror_state.json` or concurrent manual phone edits during Termux reconcile could cause data loss on `git checkout --`. Defense: `build_termux_reconcile_pull_script` fetches `origin/<branch>` FIRST, computes exact `origin/<branch>` git blob SHA-1 map (`git ls-tree -r`), reconciles ONLY files matching `live_mirror_state.json` SHA-256 OR byte-for-byte identical to `origin/<branch>`, && preserves any genuine manual phone edit via `git stash push -u` + `git pull --ff-only` + `git stash pop` (never destructive `reset --hard`). Zero secrets written to `semantic.json`, `fr_semantic`, or `resume` output.
KILL|R1|Resume Latency/Timeout Regression|`p95(resume) > 6.0s OR host_boot_timeout_count > 0`|per-turn & CI unit test|Tighten per-tier HTTP timeout to `4s`, disable optional GitHub HEAD check via `--skip-github` default on slow networks, && keep `auto_wake=False` on read probes.
KILL|R2|Hydration Clobber or Semantic Wipe|`auto_mirror_semantic_overwrite > 0 OR fresh_container_remote_clobber > 0`|unit suite + live container restart|Hard-lock `LiveSyncWatcher` to `source="auto_mirror"` + mandatory pre-push remote guard; fail unit test on any regression.
KILL|R3|Termux Reconcile Pull Failure|`termux_sync_ok == False` on mirrored-dirty repo after `ship`|every `omni_agent.py ship` + git unit test|Inspect `preservedManual` vs `reconciled` JSON telemetry && refine ignored temp-path filter (`.tmp_s25u_shots/`).
