## 2. Four Architectural Pillars of Phase 3

### 2.1 Pillar A — `Slot 2D-CAPTURE`: Mobile-DAW & Desktop In-App Black-Box Capture Suite
- **Problem Solved:** Target reference processors often live **inside mobile DAWs/apps on Android** (FL Studio Mobile, Cubasis, BandLab, Voloco, Audio Evolution) or closed desktop DAWs without standalone `.vst3` files.
- **`UnifiedSuperStimulus.wav` (Single-Pass Self-Synchronizing Master Probe, `~120–180s`):**
  1. `[Barker/MLS Chirp Sync Header #0]` -> `0.001`-sample fractional delay & clock-drift anchor via `Cavern/Restoration/SubSampleSyncEngine.cs` (`GCC-PHAT` + parabolic/Lagrange sinc interpolation).
  2. `[Dual Pass-to-Pass Determinism Gate]` -> identical stimulus repeated twice (`y_1[n] - y_2[n]`):
     - Residual `< -130 dBFS` -> strictly deterministic system -> enable phase-locked waveform `ESR` + `MR-STFT` optimization.
     - Residual `> -120 dBFS` -> isolates stochastic analog noise/dither floor or free-running asynchronous LFO -> switches optimizer to phase-invariant `MR-STFT` + Hilbert envelope modulation loss + separate noise/LFO generator parameterization.
  3. `[Multi-Level Synchronized Exponential Swept-Sines (Farina/Novak)]` @ `-36, -24, -12, -6, 0 dBFS` -> single-pass frequency deconvolution separating linear transfer function $H_1(\omega)$ (magnitude + phase) from diagonal higher-order harmonic kernels $H_2(\omega)..H_7(\omega)$ && pre-emphasis/de-emphasis curves (`Fresh Air` / Dolby-A topology).
  4. `[Prime/Irrational Sparse Multitone Carpet]` -> non-harmonic prime-spaced sinusoids exposing full **Intermodulation Distortion (IMD)** ($f_1 \pm f_2, 2f_1 - f_2$) texture + foldback aliasing above Nyquist (deducing exact internal oversampling factor `1x/2x/4x/8x` & anti-aliasing filter slope).
  5. `[Stepped-Level Tone Bursts & Hysteresis Pulses]` -> `-36 dBFS -> -3 dBFS -> -24 dBFS -> 0 dBFS` variable-duration bursts exposing compressor/transient-shaper (`Heatwave`/1176/LA-2A) attack/release trajectories, dual-stage optical memory (T4 cell), soft/hard knee, lookahead, and Peak vs. RMS detection.
  6. `[Sliding High-Q Narrow Resonances + Low/High Dual-Tone Sidechain Pumping Probe]` -> narrow-band whistle sweeps ($Q \in [8, 40]$) over pink noise + high-level low-frequency tone paired with steady high-frequency probe -> reveals dynamic spectral suppression (`Soothe2`-class) selectivity, Q-threshold, and broadband vs. multiband sidechain coupling.
  7. `[Kinematic F0 Glissando + Vibrato + Formant Chirp Probe]` -> synthetic vocal glides (`5..120 semitones/s`) + controlled vibrato (`4..8 Hz`, $\pm 10..80\text{ cents}$) -> extracts exact pitch-correction retune kinematic laws, note hysteresis deadbands, and formant preservation/warping matrices.
  8. `[Stereo & Mid/Side Cross-Coupling Probe]` -> `L-only (R=0)`, `R-only (L=0)`, `Pure Mid (L=R)`, `Pure Side (L=-R)` -> reveals dual-mono vs. RMS/Peak stereo-link ratio vs. true M/S differential processing.
  9. `[1D Knob Taper & Continuous Parameter Slew Probe]` -> anchor sweeps (`0%, 20%, 40%, 60%, 80%, 100%` or generated DAW automation project `.flm`/`.xml` ramp) -> maps non-linear UI knob taper curves && internal parameter-smoothing slew time constants (preventing zipper noise during live automation).
  10. `[Stratified Anechoic Dry Vocal Corpus]` -> whispers, chest belting, sibilants (`/s/ /sh/`), plosives (`/p/ /t/ /k/`), fry, rapid diction (`~45s` out-of-distribution validation anchor).

### 2.3 Pillar C — `Slot 2D-DNA`: Artifact-Aware Isolated Vocal Forensics & Section Timeline
- **Cross-Stem Anti-Bleed Shield (`SIR + Harmonic Confidence Gate`):**

  - Computes per-frame/per-bin Signal-to-Interference Ratio $\text{SIR}(t,f) = 10\log_{10}(|V(t,f)|^2 / |I(t,f)|^2)$ and harmonic periodicity (`VoicedProb`).

  1. **`PitchAndFormantSignature`:** Joint Vocal+Instrumental Krumhansl-Schmuckler **Musical Key & 12-bit Scale Mask**; **`ZeroCentPlateauRatio`** ($\sigma < 3.0\text{ cents}$ dwell fraction); **`StepTransitionVelocity`** ($|dF_0/dt|_{95\%} \rightarrow \text{EstimatedRetuneSpeedMs} \in [0, 120]\text{ ms}$); **`VibratoPreservationIndex`** (`5–7 Hz` modulation depth); **`CepstralFormantShiftRatio`** ($\Delta F_{1,2,3}$).
