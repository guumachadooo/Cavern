## 2. Phase 2 Execution Protocol (Self-Updating & Evolutionary)
- **Forensic Recon & Auto-Replan Waves (`MOD-RECON-SWEEP` — `W16`, `W21`, `W24`):**
  - **Zero feature coding during Recon.** Audit EVERY assigned **Slot**, **Sub-Slot**, **Neural Task Slot**, and **Code File** line by line.
  - Classify every finding as `[BUG]`, `[UNWIRED/ORPHAN]`, `[STRUCTURAL]`, or `[UPGRADE]`.
  - **Evolutionary Slot Authority (`MOD-SLOT-EVOLVE`):** Slots are **NOT frozen** to Phase 1's old 6-slot model — nor frozen to v2 below. Whenever a Recon wave finds an overloaded, missing, or redundant architectural boundary, it **MUST evolve Section 3 (Living Slot Topology)** — adding new Slots, splitting/merging existing Slots, refactoring interfaces, or extending dynamic registries — and log a `Slot Topology Delta` in Section 5 so every subsequent wave builds on the upgraded architecture.
  - **Auto-Replan Rule:** Before closing any Recon wave, **automatically update & reorganize** Section 3 & Section 4 in `PHASE2_ROADMAP.md` and `WAVE_HANDOFF.md` with exact **Slot Ownership**, **Modules (`MOD-X.Y`)**, **Target Files**, dynamic sub-splits (`W{N}.a/.b`), and **`MOD-WIRING-GATE`** checks.
- **Implementation Wave Flow (`W17–W20`, `W22–W23`, `W25–W27`):** `MOD-CONTRACT` -> `MOD-IMPL` -> `MOD-WIRING-GATE` -> `MOD-VERIFY (Python strict C#8/Android/OneUI9/L10n audit)` -> `MOD-HANDOFF`.
- **Zero-Orphan End-to-End Wiring Gate (`MOD-WIRING-GATE`, BLOCKING for EVERY implementation wave):** No wave may flip to `[x]` until an automated Python audit + explicit `UI -> Logic -> Slot/DSP -> Persistence` trace in Section 5 proves:
  1. **Zero Orphan APIs:** Every new/touched public pipeline, service, or slot method in `Cavern/` or `Cavernize.Logic/` has `>= 1` live UI-reachable caller in `CavernizeAndroid/` or the runtime loop.
  2. **Zero Stubs / No-Op Branches:** No identical `if/else` fallback branches, no dead settings toggles, no unused `AppSettingsStore` keys or model slots.
  3. **Zero Hardcoded UI Strings:** 100% `AndroidStrings.cs` EN/PT-BR coverage in every touched UI file.
  4. **Complete User Feedback Loop:** Every UI action displays real progress, result, or actionable error.
- **Principal UX/UI Design Gate (`MOD-UX-CRITIQUE`, mandatory for `W24–W27`):** Act as **Principal Mobile Product Designer + Information Architect + One UI 9 Interaction Designer**. Audit against Nielsen heuristics, cognitive load, Progressive Disclosure (Essential vs. Pro), single primary CTA per view, zero engineering jargon (`Slot 2B`, `W12`), and strict One UI 9 anti-clipping guards while preserving 100% of features.
- **Auto-Handoff Rule:** At end of EVERY wave, update: (1) `PHASE2_ROADMAP.md`, (2) `.agents/docs/WAVE_HANDOFF.md` (`<=25L`), (3) newest-first summary in `.agents/docs/PROJECT_HISTORY.md`.
