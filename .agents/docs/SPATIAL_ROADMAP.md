## 3. Unified 6-Slot Pipeline Architecture
```
[Slot 1: ISpatialDecoder]
  Atmos/TrueHD/E-AC-3/FLAC/PCM + IAMF (Eclipsa) + HOA Ambisonics + ADM BWF
      -> SpatialSceneFrame (beds + 3D objects + metadata/dialnorm + sampleRate + timestamps)
            |
            v
[Slot 2: ISpatialStageProcessor[]]  (ordered, Atmos-aware & Stereo-aware)
  2A. Parametric STFT Engine: DirAC/COMPASS Matrix 7.1 + Cavernize 3D (Legacy & Atmos-Aware Bed/Height)
  2B. Neural Stem Engine: On-device SCNet (fast mobile) / Mel-Band RoFormer (studio) -> 3D Neural Stems
            |
            v
[Slot 3: SpatialSceneHub]  (single source of truth for Audio + 3D Room + Mixer)
  SourceLayer tags: Bed | NativeObject | VirtualMatrix | VirtualHeight | NeuralStem
  ListenerPose6DoF (X,Y,Z + Yaw,Pitch,Roll) | Per-object/stem solo/mute/reposition | Soundfield telemetry
            |
            v
[Slot 4: IHeadTrackerProvider + Low-Latency Audio]
  Manual | Galaxy Buds RFCOMM | Android IMU (GameRotationVector) | BLE-OSC
  Madgwick/Kalman short-horizon angular predictor + Zero-GC LowLatency AudioTrack + USB DAC Float32/Native SR
            |
            v
[Slot 5: IBinauralRenderer]
  Near-Field Duda&Martens + Air Absorption ISO 9613-1 + Real-Time ISM Room Reflections (1st/2nd order)
  PartitionedDualConvolver + MagLS Ambisonics + Biometric ITD (Woodworth-Schlosberg) + SONICOM/Impulcifer SOFA/WAV
            |
            v
[Slot 6: IPostProcessingStage[]]  (strictly transparent / standards-based)
  AutoEq Neutral DF/B&K 5128 PEQ (auto-switched per BT/USB/3.5mm device) + HpTF ear-canal notch
  ISO 226:2023 Dynamic Equal-Loudness + ITU-R BS.1770-5 / EBU R128 + Spatial Dialog Enhancement + 0dB True-Peak Limiter
```
