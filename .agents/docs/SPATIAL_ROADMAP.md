## 2. Execution Protocol (Horizontal Multi-Wave)
- **No intermediate APK required:** User tests only at end. Still keep all C# contracts, signatures, and syntax clean + Python static-verified at end of EVERY wave to prevent compounding errors.
- **Mandatory Wave Flow:** `MOD-DISCOVERY (Audit Existing + Multi-Repo Curation)` -> `MOD-CONTRACT` -> `MOD-IMPL` -> `MOD-VERIFY (Python static C#8/Android/L10n audit)` -> `MOD-HANDOFF`.

NEVER duplicate; NEVER assume existing code is complete or SOTA — upgrade, refactor, and unify existing pieces to match roadmap spec.
- **Per-Wave Multi-Repo Curation & Zero-Reinvention Rule (`MOD-CURATE`):** **NEVER build complex DSP, codecs, drivers, models, or datasets from scratch when battle-tested open-source solutions already exist.** Inside EVERY wave's discovery, aggressively search GitHub, HuggingFace, NuGet, academic repos, and open standards; download, inspect, port, wrap, or directly bundle/integrate the best open-source repositories, C/C++/C# libraries, native ARM64 binaries/`.so`, datasets, and pre-trained ONNX checkpoints from **multiple** top projects (never locked to 1 repo per domain), keeping licenses clean (`LICENSES.txt` attribution) and recording all chosen sources in the Wave Log.
