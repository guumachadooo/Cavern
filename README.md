## Key Capabilities

### 1. Spatial Multimedia Player & In-App Library (`Play`)
- Reads embedded tags (`Title`, `Artist`, `Album`, sample rate, bitrate) and album cover art directly via Android `MediaMetadataRetriever` (or generates procedural spatial art when absent), harmonizes the frosted SF Pro UI backdrop & One UI 9 wave seekbar, and optionally auto-fetches missing HD album art and synced `.lrc` lyrics online.
- **In-App Music & Media Library (`Tocando Agora | Biblioteca`):** Built-in Samsung Music + Poweramp-inspired browser with persistent disk cache (`library_cache_v3.json`), pre-indexed off-UI-thread category grouping (`Albums | Artists | Folders | Songs`) for instant zero-freeze tab switching, direct pure-C# binary MP4 (`trkn`/`disk`/`©alb`/`©ART`), FLAC, and ID3v2 tag reading for accurate multi-disc & track-number sorting (even on `.m4a.mp4` Atmos files skipped by Android `MediaStore`), **Media Type Split (`All | Music | Videos`)**, persistent **Sort (`A–Z | Artist | Recent | Quality`)**, `180 ms` debounced search with Clear button, **Spatial / Surround** filter pills, **Smart Clean v2** evidence-based filtering (`HasEmbeddedMusicTags` decoupled from filename/folder fallbacks, evaluating SFX/voice/camera/short `<25s` rules before `IsSurround`/`IsSpatial`) with a transparent **Smart Clean Inspector** (rule toggles, hidden-track inspection, 1-tap restore/allowlist, folder hiding), **In-App Smart File Explorer** (`OneUiFileExplorerDialog`), and **Album+Artist-Scoped Variant Merging** powered by `AudioQualityAnalyzer` with an expandable live **Format Switcher (`[ Active ] +N`)**.
- **Single-Viewport Unified Player (`sf_pro_android_ui.ttf` + One UI 9) + Modular Control Layout + `[A | B]` Audio Spec Compare:** Adapts artwork, lyrics stage, and spacing dynamically to the viewport (collapsing smoothly on compact screens and landscape Lyrics) with exact 1:1 hardware-rounded album covers (`OutlineProvider` / `BitmapShader`, zero polygon clipping), a retractable bottom navigation pill, smooth 120 Hz GPU hardware-layered tab & Cover ↔ Lyrics transitions with deferred frosted-glass refresh, **One UI 9 Modular Editable Control Blocks** (long-press the top `+` pill or open Settings to reorder or hide optional Play & 3D Room blocks in-place at 120 Hz with locked essential controls & 1-tap default reset), a live **`ATMOS+FLAC`** Lossless-Twin badge pill, and a dedicated **Audio Specification** modal featuring a segmented **`[A: Original | B: ATMOS+FLAC / Spatial 3D]`** A/B toggle, live quality report refresh, collapsible Pro signal telemetry, and **Rescan Twin**, plus a unified 3-pill spatial hierarchy (**`Upmix` [Direct / Matrix 7.1 / Cavernize 3D] · `HRTF 3D` · `AI 3D / AI Atmos`** opening the **Unified Context-Aware Play/Sing AI Extraction Sheet** with multi-variant non-destructive cache switcher, exact config diffs, incremental Stage-1 vocal-stem reuse, lossless storage compaction, & inline **`(i)`** Spatial Guide), 120fps wave progress bar, unified frosted transport, Android system-linked volume bar (`Stream.Music` bidirectional sync + ISO 226 compensation), and ref-counted blurred modals.
- **Zero-Drift Syllable-Synced Lyrics & 2-Tier Apple Music Sing Dock:** Rational sample-accurate playback clock & live output-latency tracking keep lyrics locked across `44.1 kHz ↔ 48 kHz` resampling and seeks (`< 2 ms` drift), with smooth progressive syllable-by-syllable illumination (**TTML**, **Enhanced LRC**, **NetEase YRC**, **KuGou KRC/ZRCE**), two-stage automatic intro/outro credit stripping & fuzzy plain-lyrics alignment (PT-BR/EN/ES/ZH), and selectable word highlight styles (**Smooth Glow** default feathered sweep with zero white-box flash, **Minimal Clean**, or smoothly faded **Soft Word Pill**). Inside the synced Lyrics view, a 2-tier frosted Sing dock provides real-time **Vocal Level (`0%–100%`)** slider + percentage + Vocal DNA pill on Tier 1, and a scrollable row of plain-label action chips (**Karaoke**, **Keep Backing / Pure Instr.** to strip lead + backing vocals without harming instruments, **Live Mic**, **Mix-Match**, **Vocal A/B**, **Scarlett**, **AI Stems**, and **AI Cache** opening the unified context-aware Play/Sing AI sheet with multi-variant cache switcher, Atmos ↔ FLAC cross-variant reuse, incremental Stage-1 vocal reuse, lossless **Optimize Storage**, **Extract New Variant**, and per-variant or full removal) on Tier 2.
- **Ranked Online Cover Art, Lyrics & Subtitles Scrapers:** Automatic background enrichment and editable manual search supporting Title, Artist, and Album **Edition / Deluxe** preservation (`(Deluxe)`, `(Taylor's Version)`, etc.), probabilistic **match-risk scoring** enforcing strict priority (**Syllable Synced > Line Synced > Plain Lyrics**), high-res album art (`iTunes HD`, `TheAudioDB`, `CoverArtArchive`, `TMDb`), synced & plain lyrics (`Netease YRC/LRC`, `KuGou KRC`, `LRCLIB`, `Lyrics.ovh`), and `.srt` video subtitles (`OpenSubtitles` REST GZip + `Podnapisi` fallback).
- **Samsung Video Player + YouTube Video Mode (with Subtitles & Auto-Rotate Fullscreen):** Automatically switches video files into a rich video player with `CC` subtitles (`.srt`, `.vtt`, `.ass`/`.ssa` external files + online `OpenSubtitles`/Podnapisi `.srt` + FFmpeg-extracted MKV/MP4 streams), audio track switcher, aspect ratio cycling (`Fit` / `Fill` / `Stretch`), center `-10s` / `+10s` & double-tap gestures, touch lock, cutout-safe fullscreen HUD insets, and one-tap portrait/landscape fullscreen with automatic orientation restore on exit.
- Publishes `MediaSession` metadata, album art, and lockscreen transport/track-skip actions (`Previous`, `-10s`, `Play/Pause`, `+10s`, `Next`) to the Android system notification shade and lock screen.

### 2. Interactive 3D Acoustic Room & Spatial X-Ray Inspector (`Sala 3D` / `3D Room`)
- **Active Signal Chain Bar & Mini Transport:** Tappable 5-pill live signal chain overview (`Input Decoder`, `Upmix / AI 3D`, `LGSR Twin`, `Room / HRTF`, `AutoEq + Loudness`) plus compact transport & volume strip directly above the stage.
- **Volumetric 3D Room, Stereo-Pan Preserved Objects, Expressive Motion Choreography & Articulated Head Gimbal (`RoomSimulatorView`):** Architectural 3D acoustic room with translucent shaded walls, sweet-spot floor wave rings, live RMS acoustic rays, monitor bed nodes with dB level rings (Green / Amber / Red, Mute `X`, Solo gold ring across seeks & upmix rebuilds), and sculpted 3D dynamic object, AI/non-AI 3D upmix, neural stem (anchored to each stem's measured constant-power stereo-mix pan azimuth when stationary, and orbiting expressively relative to its home pan with lyrics-mood & musical-energy awareness when **Auto Motion** is enabled), and live microphone orbs with discreet dashed floor drop-lines, smooth tapered glowing Bézier motion ribbons, ceiling elevation micro-chevrons, long-press/drag 3D pinning (with instant pin reset restoring both static & dynamic Atmos trajectories), and automatic fade-out when stationary & silent (`RMS == 0`).
- **6DoF Physical Propagation Delay & Essential/Pro Spatial X-Ray Inspector:** Real-time speed-of-sound (`343 m/s`) fractional time-of-flight delay across bed/object sources (with LFE excluded), an optional **72-cell spherical 3-band Soundfield Powermap** (`All / Low / Mid / High`) with coherence-gated anti-spin dominant direction tracking, Essential summary vs. Pro telemetry (**ITU-R BS.1770-5** loudness & 4× True-Peak limiter, **LGSR Lossy vs Lossless** coupling/SPX/GCC-PHAT diagnostics, **Live Vocal Chain** metering), and one-tap **LGSR A/B** and **Vocal A/B** bypass toggles.
- **Unobstructed Room, Direct Orbit Drag & Dedicated 3D Head Trackball:** Orbit the 3D room naturally with finger-following direct manipulation (plus an optional **Invert 3D Room Orbit Drag** toggle in Settings & Fine-Tune) or drag the listener XY directly without internal HUD clutter, inspect live **Processing Tier vs. Motion Choreography Profile** status, steer **Yaw & Pitch** freely from the dedicated articulated **3D Head Trackball (`Cabeça 3D`)**, adjust elevation smoothly with the **Vertical One UI 9 Height Capsule (`Altura Y`)** below the stage, or fine-tune with `40dp` Samsung relative-drag double-tap-reset capsule sliders.
- **Live Source Mixer, Real-Time Dynamic Ceiling Filter & Laboratory Distance:** Tap any speaker/object sphere inside the room to Solo, isolate overhead activity dynamically in real time (`Height Only` tracks moving 3D objects entering/leaving the ceiling plane live), switch real laboratory loudspeaker distances (`0.50 m`–`3.25 m`) seamlessly with clickless equal-power crossfades, configure attenuation rolloff (`Disabled`, `Logarithmic`, `Linear`, `Real 1/d`), and adjust LFE.

### 3. Spatial Converter & Next-Gen Master Studio (`Estúdio` / `Studio`)
- **Unified `Master | Classic | Queue` Workflow & Pipeline Readiness Pills:** Switch cleanly between the modular mastering builder (`Master`), custom target speaker layouts (`Classic`), and the multi-file batch queue (`Queue`) with live Pipeline Readiness indicators (`FFmpeg`, `TrueHD`, `ONNX`, `Lossless Twin`) and a single contextual Primary Action button.
- **Vocal Performance Recorder, Composable Spatial Export Builder & Dynamic Atmos Motion:** Record vocal performances directly over the active track (`Record -> Preview -> Export` with automatic studio vocal chain polish), then choose a base output format (**3D Headphones**, **Cinema Surround 7.1.4**, **Dolby Atmos Master**, **Eclipsa Audio 3D**, or **360° Spatial Scene**), select an independent **Dynamic Atmos Object Motion** profile (**Off / Static**, **Subtle**, **Musical**, **Cinematic**, or **Orbit** — exporting genuine moving semantic 3D objects with time-varying ITU-R BS.2076 `ADMBlockFormat` keyframes alongside a stationary discrete 120 Hz LR4 `.1` LFE bed, plus dynamic spatial motion in IAMF, 360° HOA, 7.1.4, and binaural renders), and freely combine modular options (**AI 3D Upmix / Atmos Enhance**, **Karaoke Mode** with optional **Remove Backing Vocals / Pure Instrumental**, **Recorded Vocal Take**, **Lossless Twin Restoration**, and **Personalized Headphone Calibration**) with single-file or multi-format batch export and ITU-R BS.1770-5 / 4× True-Peak metering (`-1.0 dBTP` default).
- **Lossless Metadata, Cover Art & Synced Lyrics Embedding + Public Storage Visibility:** Preserves full audio tags (`Title`, `Artist`, `AlbumArtist`, `Album`, `Track/Disc`, `Year`, `Genre`, `Comment`) and optionally embeds real/online-fetched cover art and synchronized LRC lyrics with zero audio re-encoding (`FLAC` `VORBIS_COMMENT`+`PICTURE`, `WAV`/`RF64`/`AMB` `LIST/INFO`+`id3 ` preserving `axml`/`chna`/`dbmd` Atmos chunks, `Opus`/`M4A` FFmpeg metadata & artwork). Exports write clean human-readable filenames (`Artist - Title (Format - Badges).ext`) directly into visible public storage (**`Music/Cavernize`** default for standard audio, **`Download/Cavernize`** for specialized containers like `.iamf`/`.wv`/`.amb` or user choice) with atomic Android `MediaStore` / `MediaScannerConnection` indexing, saved public path display, and instant **Locate**, **Share**, and **Play** actions.
- Target any speaker setup from Stereo/Binaural (`Virtualizer`) up to `5.1`, `7.1`, `7.1.4`, `9.1.6`, and matrix-wired layouts with interactive wiring diagrams.
- Optionally bake the 3D Room listener position, head rotation, and active Solo/Mute overrides directly into exported files.
- Built-in batch rendering queue supporting multi-file selection directly via the in-app **Smart File Explorer** (with Android SAF fallback).

### 4. Channel, 3D Object & Neural AI Stem Extractor (`Stems`)
- **Goal-Driven Extraction Cards & Live AI Chain Preview:** Organized into 4 clear workflow goals (**Raw Channels & Bitstream**, **3D Spatial Object Renders**, **AI Source Separation (MVSEP)**, and **Harmonic & Hybrid Atmos Restoration**) with live on-device AI chain preview and contextual controls.
- Isolate bed channels and dynamic 3D objects from immersive formats (`E-AC-3 JOC`, `ADM BWF`, `DAMF`, `LAF`, `IAMF`, `WAV`, `CAF`) into individual mono WAV stems (`16-bit`, `24-bit`, `32-bit float`), per-item 3D renders, combined 3D object renders, or raw bitstream dumps.
- **On-Device SOTA Neural AI, Mobile ONNX W8A16/FP16 & SoC-Keyed QNN Cache, Studio Ensemble Bundles & Official MVSEP Cloud API:** Supports ONNX Runtime (`BS-RoFormer` / `MelBand-RoFormer` host-STFT, `SCNet`, `HTDemucs` 4/6-stem, `UVR Karaoke 2`) with pure-C# **W8A16 weight-only per-channel INT8 quantization** (`DequantizeLinear`, ~3.8× smaller footprint staying `< 1.4 GB` mobile PSS), **IEEE-754 FP16**, and **SoC-fingerprint-keyed QNN HTP Hexagon NPU context binary caching** (auto-purged on Android/ORT updates with transparent WebGPU & ARM64 KleidiAI CPU fallback), plus optional official **MVSEP Cloud REST API** offloading (`On-Device`, `MVSEP Cloud`, or `Auto Hybrid` fallback with EU mirror, cancel-safe job-hash resume, silent extra-stem pruning, **2-Stage Custom Cascade** running Lead/Backing separation strictly on Stage 1's isolated vocals stem, and **incremental Stage-1 vocal-stem reuse** skipping redundant full-mix separation across both Cloud and Local ONNX when cached vocals already exist), Lower-Mid Anchor MAP low-band vocal-rumble suppression + sub-50 Hz zero-phase HP guard, **FLAC ↔ Dolby Atmos** sub-sample **GCC-PHAT** phase- and drift-locked separate-reference Spatial Karaoke, 5 offline **Studio Multi-Pass Ensemble Bundles**, and frame-by-frame `.json` `(X, Y, Z)` 3D trajectory export.

## Building

### Requirements
- `.NET 11` SDK (`net11.0-android` workload) and Android SDK (`minSdk 26`, `targetSdk 35`, Edge-to-Edge & Predictive Back).

### Local CLI Build
```bash
dotnet publish CavernSamples/CavernizeAndroid/CavernizeAndroid.csproj \
  -c Release -f net11.0-android -p:AndroidPackageFormat=apk
```

Shared portable business logic (`Cavernize.Logic`) can also be built standalone without the Android workload:
```bash
dotnet build CavernSamples/Reusable/Cavernize.Logic/Cavernize.Logic.csproj -c Release
```

### CI / Signed Release Workflow
Pushing to `master` (or manually triggering `.github/workflows/BuildAndroid.yml`) compiles a signed 16 KB ELF-aligned ARM64 APK in GitHub Actions, publishes a permanent versioned release (`v2.9.<run>`) automatically promoted as **`Latest`**, and mirrors the binary to the rolling `android-latest` OTA alias used by the in-app updater. In parallel, `.github/workflows/FastQualityGuard.yml` verifies static guardrails, L10n parity, unit tests, native C11 pro-audio tests, and workspace file budget (`<920/999`).

## Architecture Overview
- [`Cavern/`](./Cavern) & [`Cavern.Format/`](./Cavern.Format) — Strict C# 8.0 (`netstandard2.1`) core spatial DSP engine, object renderers, neural pipelines, restoration/vocal chains, and immersive bitstream parsers (IAMF, HOA3, ADM BWF, E-AC-3 JOC, TrueHD, WAV, MKV).
- [`CavernSamples/Reusable/Cavernize.Logic/`](./CavernSamples/Reusable/Cavernize.Logic) — Shared player engine (`RealtimePlayerEngine`), ONNX WebGPU/FP16 conversion & streaming adapters, conversion environment, post-render reports, and queue logic.
- [`CavernSamples/CavernizeAndroid/`](./CavernSamples/CavernizeAndroid) — Native `.NET 11` Android One UI 9 shell, `RoomSimulatorView` 3D acoustic room, `Native/cavernize_proaudio/` (AAudio Exclusive + userspace `libusb` UAC2), Focusrite Scarlett console, ONNX Runtime bridge, and OTA updater.
- [`archive/desktop-legacy-wpf.tar.gz`](./archive/desktop-legacy-wpf.tar.gz) — Lossless SHA-256 verified archive of legacy upstream Windows WPF desktop projects (also preserved in full git history on branch `backup/cavern-pre-H-ab942fd6`), keeping the repository lean and well below AI Studio's 999-file import ceiling.
